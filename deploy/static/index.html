pscreen

Decide which compounds to test first against a protein: find pockets (including cryptic ones), dock compounds (including covalent poses), rank, and explore in 3D.

  • Upload a protein and a CSV of compounds (id,smiles).
  • Pockets from P2Rank, PocketMiner and Lacuna; GNINA docking with a covalent lane; ADMET-AI properties.
  • Everything runs in a visual workflow, repeatable, with a full export.

Status: this page is a read-only example. Running pscreen on your own protein and compounds is currently available only as a local install; a public release is planned.

Predictions only. Pockets and docked poses are computational hypotheses. A modelled covalent bond is not evidence of engagement, potency or selectivity. Scores are weak when the pocket is closed in the input structure (note the positive Vina-like value above). The example run used a 17 Å limit around Cys727 for covalent docking, which biases results toward that site.

Tools: P2Rank, PocketMiner, Lacuna, GNINA, RDKit, ADMET-AI, Mol*. See the project page for citations and licences.
